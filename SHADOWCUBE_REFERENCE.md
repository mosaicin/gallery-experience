# ShadowCube reference notes

- Stack identified from the repository: Unity 2021.3.6f LTS, URP packages, Android/WebGL project settings, C# scripts and Unity assets.

## Relevant high-level ideas

The README describes a game about waking inside a giant cubic room made of moving cubic modules, overcoming obstacles and traps, escaping to freedom, and recovering memories. The repository also contains screenshots and a developer diary link.

These ideas are treated as a high-level reference only. The current Darkland browser game remains an original Babylon.js project with its own world, names, geometry, quest flow and visual language. No ShadowCube source code, Unity assets, screenshots, logo, movie characters, or copied level data are used.

## License / permission caution

The repository contains an `AppPrivacyPolicy.md` that calls the app open source, but no separate SPDX license file or clear permissive software license was found at the inspected top level. The privacy policy is not a code license. Therefore the current project does not copy or modify ShadowCube code/assets. Any future direct code reuse should require explicit permission or a confirmed license from the repository owner.

## Adaptation decision

Safe adaptation: add an original modular-room mode to Darkland, using Babylon procedural cubes and a new memory/door rule. Unsafe adaptation avoided: reproducing the film's characters, plot, names, traps, screenshots, or ShadowCube's source implementation.
