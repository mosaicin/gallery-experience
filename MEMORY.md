# MEMORY

The reference opens with a centered “The Gallery” title on a nearly black page and a thin loading line. The implementation preserves that threshold behavior, then adds a richer explored state rather than replacing the reference's quiet first impression.

Babylon.js is loaded from deep module paths. The generated image URLs are used directly from Manus storage; no large image files are committed inside the project. The local check should be run with `pnpm exec tsc --noEmit` rather than the scaffold's watch-oriented check process, which can leave a background watcher in a memory-constrained sandbox.

No backend, database, authentication, or external API is needed for the current static experience.
