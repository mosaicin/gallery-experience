# MEMORY — Darkland Night Park Cube

The previous project was a dark interactive gallery. The current iteration repurposes the Babylon canvas as an original cubic night-park game.

The referenced public pages were retrieved successfully. They establish only a public theme and cross-links: Darkland, House of Celebrities, the channel by Jane Kravitz, an advertising contact, and a Roskomnadzor registry URL. They do not grant permission to copy content.

The game direction is therefore original: a cubic night park with an Archive House, three memory shards, a gate, and a short exploration quest. Real people and channel identities are not used as characters.

Game-specific image generation was attempted but the service returned the daily free-plan limit `20/20`. The implementation uses original procedural Babylon geometry and CSS UI, and ASSETS.md records this transparently.

Babylon.js is loaded from deep module paths. The local check should be run with `pnpm exec tsc --noEmit` rather than a watch-oriented check process.
